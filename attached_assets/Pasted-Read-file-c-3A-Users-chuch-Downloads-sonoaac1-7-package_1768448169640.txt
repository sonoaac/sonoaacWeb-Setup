### **12. VERCEL CONFIGURATION (vercel.json)**

```json
{
  "buildCommand": "npm run build",
  "installCommand": "npm install",
  "outputDirectory": "dist",
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```

**Why This Matters:**
- **buildCommand:** Tells Vercel how to build
- **installCommand:** Ensures npm installs dependencies
- **outputDirectory:** Where static files live
- **rewrites:** Routes `/` paths to index.html so React Router works
